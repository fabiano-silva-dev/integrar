# Esquemas oficiais — produção restrita

Não há XSD oficial versionado nesta entrega. Obter o pacote publicado em
https://www.gov.br/nfse/pt-br/biblioteca/documentacao-tecnica/producao-restrita
(24/11/2026 na data desta implementação), verificar a origem e extrair os
arquivos preservando a estrutura e as dependências relativas. Não instalar
schemas de terceiros nem referências externas. O diretório deve ser
somente leitura para o processo web. Configurar NFSE_DPS_XSD_RESTRITA com o
caminho absoluto do XSD raiz DPS 1.01 do pacote. Registrar versão e hash do
ZIP na homologação. Não habilitar NFSE_DPS_LOCAL_ENABLED antes da revisão do
pacote. Nenhum XML deve ser transmitido com esta entrega.
