# Analisar erro de importação

Analise o erro de importação informado no IntegraExpert.

Antes de sugerir correção, identifique:

- empresa;
- operadora;
- layout/banco;
- tipo de arquivo;
- etapa do fluxo;
- mensagem de erro;
- se ocorreu no upload, leitura, conversão, prévia, gravação ou exportação;
- se há risco de duplicidade;
- se o arquivo contém dados sensíveis;
- se o problema é do layout, do arquivo, da regra ou do sistema.

Não peça dados sensíveis desnecessários.

Entregue:

- diagnóstico provável;
- perguntas necessárias;
- próximos passos;
- se é problema de uso, layout ou bug;
- orientação para o cliente;
- orientação técnica para desenvolvimento, se necessário.

Se precisar de arquivo real, orientar a anonimizar dados sensíveis sempre que possível.
