# Responder cliente

Crie uma resposta para o cliente do IntegraExpert com base no problema informado.

Tom:

- profissional;
- claro;
- objetivo;
- educado;
- sem excesso técnico;
- sem prometer prazo impossível;
- sem assumir culpa sem análise;
- sem expor detalhes internos.

A resposta deve:

- confirmar entendimento do problema;
- explicar o próximo passo;
- orientar o cliente, se houver ação necessária;
- informar que a análise será feita;
- diferenciar dúvida de uso, erro da ferramenta e necessidade de novo layout;
- evitar termos técnicos quando não forem necessários.

Se for caso de novo layout bancário, usar a ideia:

"Layouts bancários reaproveitáveis são analisados e incorporados à evolução da plataforma conforme avaliação técnica."

Entregue uma versão curta para WhatsApp e uma versão mais formal.
