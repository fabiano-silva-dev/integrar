# Posicionamento do IntegraExpert

Ajude a descrever o IntegraExpert de forma clara para escritórios de contabilidade.

O produto deve ser posicionado como:

Uma ferramenta de automação contábil bancária para escritórios, que transforma extratos bancários em lançamentos conferíveis e exportáveis para o Domínio.

Fluxo principal:

Importar → Amarrar → Conferir → Exportar

Evitar posicionar como:

- apenas conversor de PDF;
- apenas importador de OFX;
- sisteminha auxiliar;
- substituto completo do contador;
- automação perfeita sem conferência.

Destacar:

- redução de digitação;
- padronização de históricos;
- regras de amarração;
- conferência;
- exportação para Domínio;
- novos layouts bancários reaproveitáveis;
- suporte inicial assistido;
- ganho de produtividade.

Entregue:

- frase curta;
- descrição de 1 parágrafo;
- descrição comercial;
- explicação para demonstração;
- texto para WhatsApp.
