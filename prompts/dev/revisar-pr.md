# Revisar PR

Revise as alterações atuais como se fosse um Pull Request do projeto IntegraExpert.

Não altere código ainda.

Analise:

- clareza da implementação;
- risco de regressão;
- impacto em multi-tenant;
- impacto em UX;
- validações no backend;
- segurança;
- performance;
- consistência com Laravel, Livewire e Blade;
- necessidade de testes;
- pontos de manutenção futura.

Entregue a revisão com:

- resumo geral;
- pontos positivos;
- problemas encontrados;
- riscos críticos;
- melhorias recomendadas;
- testes que deveriam existir;
- decisão sugerida: aprovar, aprovar com ajustes ou revisar antes de merge.

Não use comentários genéricos. Seja específico nos arquivos e trechos relevantes.
